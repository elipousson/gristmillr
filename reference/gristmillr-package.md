# gristmillr: Work with the 'Grist' Spreadsheet API

Read and write data in 'Grist' <https://www.getgrist.com/> documents
using the 'Grist' REST API. Functions are built on 'httr2', take and
return data frames, and use plain handle objects instead of stateful
classes so they work well in tidyverse-style pipelines.
